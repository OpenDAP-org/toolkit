# Toolkit

Developer host tools (not shipped in OpenDAP OS): build, flash, emulation, publish, templates.

## Layout

- `host/` — developer host setup (`host/setup.sh`)
- `hooks/` — shared pre-commit hooks (see `.pre-commit-hooks.yaml`)
- `crates/`
- `templates/`
- `docs/`
